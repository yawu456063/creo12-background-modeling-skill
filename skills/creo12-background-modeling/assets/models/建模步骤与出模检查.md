# 吨吨杯第四版：建模步骤与出模检查

日期：2026-10-21。单位：毫米。此版为结构设计稿。

## 打开模型

将整个文件夹放在同一目录，用 Creo 12 打开 `dundun_cup_mold_v4_final.asm.1`。目录内 11 个零件文件需要一并保留。装配原生 Y 方向为高度方向；预览按竖直方向显示。

## 实际建模顺序

1. 在独立 Creo 12 无图形会话中，通过同步 Object TOOLKIT Java 回调获取 Session。
2. 设定毫米单位，使用封闭旋转剖面生成杯身、杯盖、底护套、护圈和密封圈等回转件。
3. 生成上下抱箍轮廓并拉伸，切除安装耳贯穿减胶孔，再建立 1.5° 拔模特征。
4. 生成 C 形提手实体，移除宽侧面建立 2.2 壳厚特征，再建立 1.5° 拔模特征。
5. 用实际几何轴心补偿定位偏移，将全部 11 个零件装配并固定，保存最终装配。
6. 在另一独立 Creo 会话重开最终文件，重新生成，核对零件数量、体积、位置矩阵、原生壳与拔模特征，并计算装配干涉。
7. 从最终零件导出 STL，进行局部开模方向网格筛查并生成真实几何预览。

旋转剖面自带的斜壁没有单列 DRAFT 特征；提手及两只抱箍则有原生 DRAFT。预览配色用于辨认部件，未写入原生模型外观。

## 已完成的验证

- 最终文件独立重开、再生通过：11/11 个零件，11/11 定位矩阵匹配，11/11 固定。
- 装配干涉数量 0。零干涉不能证明压紧、密封或强度合格。
- 原生特征核对：SHELL 1 个，DRAFT 3 个。
- 杯盖指定旋转剖面的轴向射线检查：第三版最多穿过 5 段材料，第四版最多 1 段；第四版被检查的非水平剖面边无零斜度边。
- 提手与上下抱箍按局部拉伸轴、0.12 间距做网格射线筛查，均未检出多段材料射线。精确数量见 `pull-test.json`。
- 射线筛查是离散几何检查，不能替代完整分型、顶出、弹性变形、模流和实际试模验证。

## 对照用户提供教材的判断

来源：《注塑模具设计实用教程》张维合，用户提供的扫描 PDF。以下页码为书内印刷页；PDF 物理页序号另列。

- 第 32 页（PDF 第 45 页）：尽量均匀壁厚，厚薄变化会影响冷却收缩、缩痕与变形。因此减薄杯盖和抽壳提手，抱箍安装耳做减胶。
- 第 38–39 页（PDF 第 51–52 页）：收缩抱紧及表面状态影响脱模，拔模角需结合材料、深度、表面等确定。
- 第 41 页（PDF 第 54 页）：圆角及加强结构应避免应力集中和过厚截面。本版握持边缘圆角及局部壁厚仍需继续核定。
- 第 89 页（PDF 第 102 页）：晒纹腔体斜度通常随纹理细度在 3°–9° 范围考虑。属于教材经验指导，不能替代具体纹理供应商要求。当前杯盖约 2.974° 外壁不能直接判定适合晒纹。
- 第 133–134 页（PDF 第 146–147 页）：侧向凹凸等结构会引入侧抽芯问题。本版取消原先周向槽，降低轴向开模阻挡风险。

书中经验值与本模型计算值分开使用；教材本身不是针对本产品的试模报告。

## 仍需完成的工程事项

确定具体树脂牌号与收缩率、弹性体硬度和压缩量；设计实际锁紧/紧固方式；补足握持和装配圆角；明确各零件分型、顶出、浇口、排气及冷却；校核装配公差、密封、提手强度和跌落性能。若选择晒纹，需先确定纹号、纹深与方向，再修订相关面的拔模和尺寸。此版不构成可直接开模的生产图。
